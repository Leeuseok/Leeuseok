## 📖 최근 프로젝트 도감

<details open>
<summary><b>No.001 — 사내 업무 웹 서비스</b> <code>2025.10–현재</code> <sub>Company · Front-end</sub></summary>
<br />
재직 중인 회사에서 업무용 웹 서비스의 프론트엔드 화면을 구현하고 있습니다.<br />
React 19, TypeScript, Vite, Tailwind CSS를 바탕으로 TanStack Query·Table·Virtual, Zustand, Axios를 사용해 데이터 조회·대용량 테이블·폼 화면을 만들고, 엑셀·PDF 처리 기능도 다룹니다.
</details>

<details>
<summary><b>No.002 — Threads 콘텐츠 자동 게시 봇</b> <code>2026.10</code> <sub>Private</sub></summary>
<br />
Python과 Threads API를 연결해 하루 5회 예약 발행하고, GitHub Actions로 스케줄을 자동화했습니다.<br />
매일 조회수를 수집해 성과가 좋은 글을 선별하며, 14일 후 문장을 새로 작성해 재게시하는 흐름을 구성했습니다.<br />
유사도 60% 초과 차단, 일일 재게시 제한, 광고 문구 자동 삽입 등 운영 규칙도 코드에 포함했습니다.
</details>

<details>

<br />
역사 인물의 발자취를 따라 코스를 걷고, 위치 기반 방문 인증으로 스탬프를 모으는 모바일 앱입니다.<br />

카카오·네이버 소셜 로그인, 코스 상세·커스텀 코스·내 여행·스탬프 API 연동, 위치 권한 안내와 방문 인증, 주변 추천 장소, 네이버 지도 길찾기를 구현했습니다.<br />
공통 얼럿 모달, 당겨서 새로고침, 화면 복귀 시 재조회 등 사용성을 다듬고 운영 서버 연결과 Android 빌드까지 진행했으며, React·Vite 기반 관리자 페이지의 API 정합성 보정에도 참여했습니다.
</details>
